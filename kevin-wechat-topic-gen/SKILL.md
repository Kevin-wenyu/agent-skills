# 公众号选题生成

## 这个 skill 做什么

输入一个话题、事件或关键词，输出3-4个可选的文章方向，每个方向结构完整、彼此有真实差异，附诚实的优劣分析，交给用户选。本 skill 只做选题这一步，不调研、不写初稿。

## 执行步骤

### 1. 理解输入

用户可能给一个话题、一条新闻、一个产品发布，或者只是一句"最近想写XX"。如果信息太模糊（比如只有一个专有名词，看不出想强调什么），先问一句想强调的重点或目标读者是谁，不用问太细，能开始生成就开始。

### 2. 生成3-4个选题方向

每个方向必须是真正不同的角度，不是同一个意思换种说法。可以参考这几类方向去组合（不用照搬，按话题特点调整）：

- 深度评测/体验型——亲自用过、给出真实评价
- 实战教程型——手把手怎么做
- 洞察观点型——对现象的判断和预测
- 案例拆解型——拆一个具体案例/产品/项目

每个方向要包含：

- 标题（1-2个候选）
- 核心角度——一句话说清楚这篇文章想让读者带走什么
- 大纲——3-5个要点
- 工作量评估——用星级 ⭐ 到 ⭐⭐⭐⭐⭐，越多代表越费时间/需要素材越多
- 优劣分析——优势可以写，但**劣势必须明确、具体**，比如"这个角度已经有同类文章，差异化空间有限"或"需要大量实测数据，工作量是其他方向的2倍"。不能每个方向都只夸不说缺点，如果说不出具体劣势，说明这个方向本身不够扎实，考虑换一个。

### 3. 交给用户选，不要自己拍板

列完方案后停下来，明确问"选哪个方向，还是要调整/合并几个"。等用户确认了方向，再结束本 skill 的执行，把选定的方向交给下一步（调研或直接写作）。

## 边界

- 只做选题，不调研、不写初稿、不配图。
- 方案数量控制在3-4个：2个选择感不够，5个以上会让人决策疲劳。
- 每个方案必须有至少一条明确的劣势，不能全是夸奖。
